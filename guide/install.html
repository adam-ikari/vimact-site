安装 ​

VimAct 是一个 APK，加一个必须手动打开的系统开关。装完不等于能用了，两件事得分开做。

前提 ​

  • Android 10（API 29）或更高。这个数字是构建里定的下限，图的是主流设备覆盖；按键过滤本身从 API 18 就具备，不是它卡住了版本。低于 29 的设备，安装器会直接拒绝这个包。
  • 一把物理键盘：蓝牙、USB、平板或折叠屏的内置键盘都算。纯触屏手机用不上这个工具。
  • 允许侧载。软件当前不在应用商店，来源见下载。

装 APK ​

从下载取一个 APK，用文件管理器打开并安装。系统会要求你确认「允许来自此来源的应用」，一次性授权即可。

安装本身不会让 VimAct 开始工作。它此刻只是躺在系统里，没有拿到任何读取屏幕的能力。

打开无障碍服务 ​

这是必需的一步，原因见启用无障碍服务。

最快的路径是启动 VimAct，主页点「Open accessibility settings」，系统会打开无障碍设置页，在里面找到 VimAct 打开即可。

打开之后回到 VimAct 主页，顶部那行状态文字应当变成 Status: enabled。如果还是 disabled，说明开关没落到系统里，常见原因是 ROM 需要多确认一层授权弹窗。

试一下 ​

切到任意 App，按一下 F。屏幕上的可点击元素左上角应该弹出黄色小标签。

第一次按 F 没有任何反应，通常是这几个原因：状态行还是 disabled；当前 App 被加进了排除列表；输入法正弹着（此时 VimAct 会让路，见常见问题）。还有一种最容易漏：状态行显示 enabled、服务进程却被 ROM 冻结或杀掉了——主页那行状态读的是系统设置里的开关值，开关开着它就写 enabled，进程死不死它不知道。按启用无障碍服务里的三条 ROM 排查走。

卸载 ​

先在系统无障碍设置里关掉 VimAct 的服务开关，再卸载 APK。顺序反过来也不会留下残余，无障碍服务随应用一起消失，但先关服务能让你确认卸载前它已经停止介入。
