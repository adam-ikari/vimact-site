下载 ​

VimAct 通过本网站分发 APK。下载入口在本页，APK 文件和校验值放在站点仓库的 Releases 里。

系统要求：Android 10（API 29）及以上，配一把物理键盘。安装不用挑架构：一个包里 arm64-v8a、armeabi-v7a、x86、x86_64 四套都装着，任何机器拿到的都是同一个文件。原生库也只有一个，是 AndroidX 图形库顺着 Compose 的依赖链带进来的 libandroidx.graphics.path.so，每个架构一份、单份不到 11 KB；本项目自己不含原生代码。

两个渠道 ​

渠道版本名形式定位发布条件
正式版0.1.0日常可用最高级别混淆 + 正式签名 + 真机验证通过
测试版0.2.0-beta、0.2.0-beta.2提前尝新，随时可能坏最高级别混淆 + 正式签名，不等真机验证结论

没有第三条渠道。debug 构建是开发机上联调用的，混淆关闭、用调试签名，不具备发布条件，也不会出现在下载页上。

两个渠道由同一把签名密钥签发，因此可以互相覆盖安装，不需要先卸载。能不能覆盖安装，系统看的是 versionCode，不是版本名：装进更小的 versionCode 会被拒绝，那种情况先卸载再装。

版本号按语义化版本走，MAJOR.MINOR.PATCH，当前处于 0.x 阶段。版本名写在 app/build.gradle.kts 的 baseVersionName 里，测试版的 -beta 后缀由 beta 构建类型自动追加；同一轮迭代里出第二个、第三个测试版，后缀带序号 -beta.2、-beta.3，序号取 tag 尾巴上那个数。发下一轮时改 baseVersionName 这一行，并把 versionCode 抬上去，两处都还是手工。文件名格式 vimact-<版本名>-<渠道>.apk，版本名取的也是 baseVersionName，渠道直接写在结尾，装错包一眼能看出来。

当前状态 ​

两个渠道都还没有可下载的构建。

构建链已经就位：R8 full mode、类打平到默认包、方法名激进重载、资源压缩、不保留行号与源文件名，正式版和测试版共用同一份混淆配置。发布脚本挡在三处：未签名的产物不发，tag 与 APK 里版本名不一致的不发，正式版没过真机验证的不发。

剩下的两件事都在人身上：一把正式签名密钥，以及一次真机验证。混淆后的 release 构建在没有装机跑通之前是未知量，把未知量发给用户比晚几天发布更糟。

完整性校验 ​

每个 APK 旁边都提供 SHA-256，列在对应 Release 的正文里。下载后核对：

sha256sum vimact-<版本名>-release.apk

对不上就不要装。

权限清单 ​

APK 不声明 INTERNET。整份清单上只有一条：com.vimact.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION，AndroidX 合并 manifest 时自动加上的，由本应用自己定义，protectionLevel 是 signature，同签名的应用才请求得到，跟系统敏感权限无关。装机时系统弹出的权限请求仍然是空。

它能读屏幕和派发点击，全部来自你在系统设置里手动授予的无障碍服务，撤销随时生效。不申请录屏权限，不申请存储权限，不含第三方分析 SDK。

安装 ​

拿到 APK 后用文件管理器打开安装，允许一次「来自此来源的应用」。装完必须去开无障碍服务，否则一切都不会发生，步骤见启用无障碍服务。

关于自行构建 ​

源码当前未公开，暂时无法自行构建复现。这一点会随源码计划一起更新。

最后更新:

VimAct 目前处于 v0.1 阶段，行为可能随版本调整。

本地优先：无网络请求、无遥测、无第三方 SDK。
